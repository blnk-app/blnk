Розв’язання проблем

Часті випадки, їхні причини й що робити. Якщо вашого випадку тут немає, напишіть у підтримку на GitHub.

Гаряча клавіша не спрацьовує в PowerShell або Диспетчері завдань

Найімовірніше, вікно запущене від імені адміністратора. Windows не передає клавіші таких вікон звичайним програмам. Клацніть по іншому вікну чи робочому столу або виберіть знімок у меню значка BLNK у треї. У наступній версії над такими вікнами запрацюють сполучення з Ctrl, Alt, Shift або Win, але не одиночні клавіші. Докладніше — в інструкції «Гарячі клавіші».

Клавіша з Logi Options+ або іншої утиліти не спрацьовує

Якщо натискання надсилає утиліта, а не сама клавіатура, над вікнами адміністратора воно не дійде до жодної програми. Це обмеження Windows. У звичайних вікнах така клавіша працює.

Запис екрана не починається за клавішею

У запису екрана немає клавіші за замовчуванням. Призначте її в «Налаштування» → «Гарячі клавіші».

Esc не зупиняє запис

Над вікном, запущеним від імені адміністратора, Esc до BLNK не доходить. Зупиніть запис кнопкою «Стоп» на панелі або повторним натисканням гарячої клавіші запису.

У записі немає звуку

  • Звук комп’ютера й мікрофон за замовчуванням вимкнені. Увімкніть їх у «Налаштування» → «Знімок» → «Запис екрана».
  • Перевірте кнопки звуку й мікрофона на панелі запису: можливо, джерело вимкнене.
  • BLNK записує мікрофон, вибраний у Windows за замовчуванням.
  • У GIF звуку немає. Для запису зі звуком виберіть MP4.

GIF обривається через хвилину

GIF розрахований на короткі ролики: до хвилини, не ширший за 960 точок і до 15 кадрів на секунду. Для довгих записів виберіть MP4, він пише до 30 хвилин.

Кольори у відео трохи розмиті

Відео зберігається в H.264 з кольором 4:2:0, як майже всі файли MP4. Тонкі кольорові краї згладженого шрифту (ClearType) при цьому трохи пом’якшуються, це нормально. Білий текст, який жовтів у ранніх версіях, виправлено в 0.1.0-beta.10.

Історія займає багато місця

Один запис в історії — близько 0,25 МБ. Зменште ліміт у «Налаштування» → «Збереження» → «Історія»: 100, 500, 1000 або 5000 записів. Старі записи видаляються з історії самі, файли в теці знімків залишаються.

Windows показує попередження під час встановлення

Інсталятор поки не підписаний сертифікатом розробника, тому SmartScreen може його не розпізнати. Натисніть «Докладніше», а потім «Усе одно запустити». Завантажуйте BLNK лише зі сторінки завантаження.

Немає свіжої версії для Windows ARM64

Збірки для Windows ARM64 поки залишаються на версії 0.1.0-beta.4. Нові з’являться після 1 грудня 2026 року. Версія для macOS у тестуванні.
