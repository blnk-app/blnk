Troubleshooting

Common cases, their causes and what to do. If yours isn’t here, ask in support on GitHub.

A hotkey doesn’t work in PowerShell or Task Manager

The window most likely runs as administrator. Windows doesn’t pass the keys of such windows to normal programs. Click another window or the desktop, or choose a capture from the BLNK icon menu in the tray. In the next version, shortcuts with Ctrl, Alt, Shift or Win will work over these windows, but single keys won’t. See the Hotkeys guide.

A key from Logi Options+ or another utility doesn’t work

If a key press comes from a utility rather than the keyboard itself, it reaches no program over administrator windows. This is a Windows limit. In normal windows the key works.

Screen recording doesn’t start from a key

Record screen has no default key. Set one under Settings → Hotkeys.

Esc doesn’t stop a recording

Over a window that runs as administrator, Esc doesn’t reach BLNK. Stop the recording with the Stop button on the panel or the recording hotkey.

A recording has no sound

  • Computer sound and the microphone are off by default. Turn them on under Settings → Capture → Screen recording.
  • Check the sound and microphone buttons on the recording panel: a source may be muted.
  • BLNK records the default microphone in Windows.
  • GIFs have no sound. Choose MP4 to record with sound.

A GIF stops after a minute

GIF is meant for short clips: up to a minute, at most 960 pixels wide and up to 15 frames per second. For longer recordings choose MP4, which records up to 30 minutes.

Colours in a video look slightly soft

Videos are saved as H.264 with 4:2:0 colour, like almost every MP4 file. The thin coloured edges of smoothed text (ClearType) get a little softer, which is normal. White text that turned yellow in earlier versions was fixed in 0.1.0-beta.10.

History takes a lot of space

Each history entry is about 0.25 MB. Lower the limit under Settings → Saving → History: 100, 500, 1000 or 5000 entries. Old entries leave history by themselves, and the files in your screenshots folder stay.

Windows shows a warning when installing

The installer is not signed with a code-signing certificate yet, so SmartScreen may not recognise it. Choose More info, then Run anyway. Only download BLNK from the download page.

No recent version for Windows ARM64

Windows ARM64 builds stay on version 0.1.0-beta.4 for now. New ones will come after 1 December 2026. The macOS version is in testing.

Didn’t find your case? Describe it in support on GitHub.
