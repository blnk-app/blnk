BLNK hotkeys

The default keys, how to set your own, and where Windows keeps every program away from the keyboard.

Default keys

ActionKey
Capture areaPrtSc
Capture screenShift+PrtSc
Capture windowCtrl+PrtSc
Record screenNot set

The same actions are in the BLNK icon menu in the system tray.

How to change a key

  1. Open Settings → Hotkeys.
  2. Click Change next to an action and press the new key or shortcut. Esc cancels.
  3. When the key works, a Works mark appears next to it.

Default brings back the original key, Disable removes it, and Reset all restores every key.

Single key or shortcut

A hotkey can be a single key or a shortcut with Ctrl, Alt, Shift and Win. A single key is captured in every program: you can’t type it, and it stops working while you type text. Pause and F13–F24 make better single keys. If Windows already uses the shortcut you pick, BLNK suggests a free one with Ctrl+Alt.

BLNK catches hotkeys before other programs, PrtSc included. So if a key is also set in Lightshot, ShareX or a keyboard utility, BLNK gets it in normal windows.

Windows limits

Windows protects windows that run as administrator: an administrator PowerShell or Command Prompt, Task Manager, installers. Normal programs don’t receive key presses while such a window is active.

  • In version 0.1.0-beta.10, BLNK hotkeys don’t work over these windows. Click another window or the desktop, or choose a capture from the BLNK icon menu in the tray.
  • In the next version, shortcuts with Ctrl, Alt, Shift or Win will work over these windows. Single keys such as PrtSc, End or F keys won’t: that is Windows protection. If you often capture over administrator windows, use a shortcut with a modifier.
  • Keys from utilities. If a key press comes from a program such as Logi Options+ rather than the keyboard itself, it reaches no program over administrator windows.
  • Esc during a recording doesn’t stop it over an administrator window. Press Stop on the panel or the recording hotkey again.

You don’t need to run BLNK as administrator. Other common cases are in troubleshooting.

Questions and answers

Can I use a single key without Ctrl or Alt?

Yes. But that key is captured in every program, so you won’t be able to type it. Pause, F13–F24 or a Ctrl+Alt shortcut work better.

Lightshot or ShareX already uses PrtSc. What happens?

BLNK catches hotkeys before other programs, so in normal windows BLNK gets the key.

Why doesn’t the hotkey work in Task Manager?

Task Manager runs as administrator, and Windows doesn’t pass the keys of such windows to normal programs. See the Windows limits section below.
