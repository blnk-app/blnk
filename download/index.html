How to install BLNK

  1. Download the installer and run it.
  2. If Windows shows a SmartScreen warning for a file you downloaded from this page, choose More info, then Run anyway.
  3. Choose your hotkeys on the first-run screen and check that they work.
  4. BLNK stays in the system tray. Press PrtSc to take a screenshot.

What to do next is covered in the Getting started guide.

Updates

BLNK checks GitHub for a new version at startup and once a day. It asks before installing, and verifies the update signature first. You can turn automatic checks off in the About section of the settings.

Looking for another build? See what changed in each version or open all releases on GitHub.

Questions and answers

Is BLNK safe to install?

BLNK has no ads, accounts or telemetry. Download it only from this page or from the official GitHub releases.

Why does Windows show a warning?

The installer is not signed with a code-signing certificate yet, so SmartScreen may not recognise it. Updates are signed separately and verified by BLNK before they are installed.

Is BLNK still in beta?

Yes. BLNK is in public beta, so some features may change between versions.

How do I uninstall BLNK?

Open Installed apps in Windows Settings, find BLNK and choose Uninstall.
