Share a screenshot with a private link

BLNK uploads a screenshot to storage you control and copies the link to the clipboard. Your files never pass through a BLNK service.

Supported storage

StorageWhat you need
S3 and Cloudflare R2Endpoint, bucket, access keys and a public address
Your HTTP addressAn upload address, optional headers and the link field in the reply
FTP and FTPSServer, user name, password and a public address
SFTPServer, user name, password or key file and a public address
Google DriveSign in with Google in your browser, a folder on Drive and who can open the link. BLNK only sees files it created

What makes the link private

  • The file name is 22 random characters, so the link can't be guessed.
  • The uploaded image contains only pixels, with no EXIF or other metadata.
  • SFTP checks the server key before connecting.

How to share a screenshot

  1. Open the Upload section of the settings, add your storage and press Test.
  2. Take a screenshot and choose Upload and copy link, or press Ctrl+U.
  3. Paste the link from the clipboard wherever you need it.

Screen recordings upload the same way: from history, or right after you stop if Upload right away is on in the recording settings.

Before sharing, hide private data on the screenshot.

Questions and answers

Does BLNK host my screenshots?

No. Screenshots go directly to the storage you configure.

Who can open the link?

Anyone who has the link, if your storage allows public reading. The random file name makes the link very hard to guess. On Google Drive you choose: anyone with the link, your organization or only you.

Where are my storage passwords kept?

In Windows Credential Manager, not in BLNK files.

Can I delete an uploaded screenshot?

Yes. Use Delete from server in the BLNK history.
