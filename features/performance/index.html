A lightweight screenshot tool written in Rust

BLNK is a native app written in Rust. It does not use Electron, and it draws the selection and annotations without a browser engine.

Why BLNK stays small

  • The main work happens in native code, without a bundled browser engine.
  • BLNK waits in the tray and opens heavier windows only on request.
  • Recording relies on the video encoder already included in Windows.

Questions and answers

Does BLNK use Electron?

No. BLNK is a native Rust application.

Why does BLNK use WebView2 at all?

The settings and history windows use Microsoft WebView2. It starts only when you open those windows.

Does BLNK need FFmpeg for recording?

No. Screen recording uses the H.264 encoder built into Windows.
